# বুঝেছি? — ক্লাসে "বুঝেছি / বুঝিনি" ফিডব্যাক ও কুইজ

শিক্ষকের অ্যান্ড্রয়েড ফোনই সার্ভার। শিক্ষার্থীরা QR স্ক্যান করে ব্রাউজারে যুক্ত হয়, কোনো অ্যাপ বা ইন্টারনেট লাগে না।

## কী আছে
- 🟢 বুঝেছি / 🟡 একটু বুঝেছি / 🔴 বুঝিনি — শুধু শিক্ষক নামসহ দেখেন, লাল বেশি হলে ফোন কাঁপে
- এক ফোনে একাধিক শিক্ষার্থী (বন্ধুর ফোন শেয়ার), আলাদা ট্যাবে
- MCQ কুইজ (৫-৭টি): একটা একটা করে বা একসাথে, টাইমার, লাইভ ভোট, উত্তর ও ব্যাখ্যা দেখানো
- AI দিয়ে MCQ বানানো (ঐচ্ছিক, নিজের API কী লাগে)
- ক্লাস শেষে রিপোর্ট ও শিক্ষার্থী-ভিত্তিক পরিসংখ্যান (সব SQLite-এ, শুধু ফোনে)

## বিল্ড
**GitHub Actions:** রিপোতে পুশ করুন → Actions → *Build APK* → `bujhechhi-apk` আর্টিফ্যাক্ট ডাউনলোড।
**Android Studio:** ফোল্ডারটি খুলুন (Gradle 8.10+, JDK 17) → Run।

## কোড কাঠামো
- `app/.../core` — পুরো যুক্তি (Android ছাড়া, JVM-এ টেস্টযোগ্য): `ClassCore`, `Report`, `AiQuiz`, `Json`
- `app/.../server` — Ktor সার্ভার (`KtorHost`), `ClassEngine`, ফোরগ্রাউন্ড সার্ভিস
- `app/.../data` — SQLite (`SqliteStore`), সেটিংস
- `app/.../ui` — Jetpack Compose স্ক্রিন
- `app/src/main/assets/student` — শিক্ষার্থীর পেজ (একটি HTML + বাংলা ফন্ট)

## পরীক্ষা
- `core-test/` — মূল যুক্তির টেস্ট (CI-তে চলে): `kotlinc core/*.kt core-test/MemStore.kt core-test/CoreTest.kt`
- `tools/` — আসল `ClassCore` + Node WebSocket + Playwright দিয়ে শিক্ষার্থীর পেজের end-to-end টেস্ট
